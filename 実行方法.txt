🎯 システム概要

YouTube Live のコメントを自動で取得し、Dify に送信してAI応答を生成し、
その応答を YouTube Liveチャットへ投稿します。
さらに、Cartesiaで音声化（TTS）する構成へ拡張できます。

このシステムは PowerShell モジュールを分割した構成になっており、
各モジュールが役割を担当し、main.ps1 で連携して動作します。

────────────────────────
■ 事前準備
────────────────────────

事前準備.txt を参照してください。

最低限必要なもの：

- Google / YouTube API の認証情報
- Dify APIキー
- config/mykey.json
- config/youtube_tokens.json
- PowerShell
- YouTube Live配信環境

秘密情報を含むため、以下はGitHubへコミットしないでください。

- config/mykey.json
- config/youtube_tokens.json
- .env
- APIキーやトークンを含むファイル

🎯 実行方法
────────────────────────

PowerShellを起動し、AI_STREAM フォルダへ移動してから実行します。

例：

cd path\to\AI_STREAM

powershell -ExecutionPolicy Bypass -File .\main.ps1

または、Windows上で exe.bat をダブルクリックして起動します。

投稿せずに動作確認だけしたい場合：

powershell -ExecutionPolicy Bypass -File .\main.ps1 -DryRun

※ 特定の固定フォルダに置く必要はありません。
※ main.ps1 が置かれているフォルダをプロジェクトルートとして動作します。

────────────────────────
🧩 モジュール構成
────────────────────────

mod01.psm1：
JSONユーティリティ。
設定、トークン、ログの入出力で共通利用。

mod02.psm1：
認証ゲートキーパー。
アクセストークンの有効期限を確認し、期限切れ時のみ mod03 を呼び出します。

mod03.psm1：
リフレッシュ実行。
refresh_token を使って access_token を再発行・保存します。

mod04.psm1：
URLからYouTube videoIdを抽出します。

mod05.psm1：
配信検出・liveChatId特定。
現在のライブ配信を検出し、videoId / liveChatId を取得します。

mod06.psm1：
コメント取得。
YouTube Liveチャットをポーリングして新着コメントを取得します。

mod07.psm1：
Dify応答。
コメント本文をDify APIへ送信し、応答テキストを取得します。

mod08.psm1：
YouTube投稿。
応答テキストをYouTube Liveチャットへ投稿します。

mod09_text_sanitize.psm1：
YouTube投稿前の文章整形。
改行、空白、長文を安全な形に整えます。

main.ps1：
統合エントリ。
認証 → 配信検出 → コメント取得 → Dify応答 → YouTube投稿 を実行します。

────────────────────────
⚙️ main.ps1 の処理フロー
────────────────────────

1. プロジェクトルートを判定
   - 通常は main.ps1 の配置場所を基準にします。

2. モジュール読込
   - mod フォルダ内の psm1 ファイルを読み込みます。

3. 設定読込
   - config/mykey.json を読み込みます。

4. Google認証
   - アクセストークンを確認します。
   - 期限切れの場合は更新します。

5. 配信検出
   - 現在配信中のYouTube Liveを検出します。
   - liveChatId を取得します。

6. チャット監視
   - YouTube Live APIでコメントを一定間隔で取得します。

7. AI応答
   - コメント本文をDifyへ送信します。
   - Difyから応答テキストを受け取ります。

8. 投稿前整形
   - 応答テキストをYouTubeチャット向けに整形します。

9. YouTube投稿
   - 整形済みの応答をLiveチャットへ投稿します。

────────────────────────
🔑 設定ファイル
────────────────────────

設定ファイルは config フォルダに置きます。

config/
├─ mykey.json
├─ mykey.sample.json
└─ youtube_tokens.json

mykey.json：
Dify APIキー、Cartesia APIキー、各種設定を入れるファイルです。
秘匿性が高いためGitHubにコミットしないでください。

youtube_tokens.json：
YouTube API用のアクセストークン、リフレッシュトークンを保存するファイルです。
アクセストークンは自動更新対象です。
リフレッシュトークンが期限切れになった場合は、認可URLから手動更新します。

────────────────────────
■ トラブル時の見方
────────────────────────

認証エラー：
- config/youtube_tokens.json を確認
- Refresh Token の期限切れを確認
- PCの時刻ズレを確認

AI応答が返らない：
- Dify APIキーを確認
- Dify API URLを確認
- Dify側の利用上限を確認

コメントが拾えない：
- YouTube Liveが配信中か確認
- ライブチャットが有効か確認
- liveChatId が取得できているか確認

投稿されない：
- YouTube Data APIの権限を確認
- アクセストークンのスコープを確認
- 投稿文が空文字になっていないか確認
